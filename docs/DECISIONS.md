# Решения

| Дата | Решение | Почему |
|---|---|---|
| 2026-11-01 | Godot 4.7.2 (stable), GDScript, Forward+ | Последняя стабильная, удобна для агентной разработки, лучший рендер в Godot |
| 2026-11-01 | Рендер в облаке через lavapipe + Xvfb | Нет GPU; даёт настоящий Forward+ для скриншотов |
| 2026-11-01 | Планеты — процедурно в Godot (quadtree), не в Blender | Планеты огромные, нужен LOD в рантайме и посадка в любой точке |
| 2026-11-01 | Blender — headless Python-скрипты для корабля/пропсов, без Blender MCP | Воспроизводимо, параллелится, не нужен GUI |
| 2026-11-01 | Без Godot MCP — свои CLI-скрипты (`tools/`) | MCP рассчитан на живой редактор; CLI надёжнее в облаке |
| 2026-11-01 | Floating origin, сжатая система (радиусы 10–60 км, газ-гигант 300 км) | float32 в узлах; зрелищность и короткие перелёты |
| 2026-11-01 | Сборка Windows в GitHub Actions, nightly-релиз на каждый пуш в main | Пользователь быстро скачивает свежий билд |
| 2026-11-01 | Небо: дорогой фон (Млечный путь, туманности, галактика) запекается один раз в HDR cube-atlas через SubViewport; звёзды — per-pixel | Красиво и дёшево в рантайме, без мерцания |
| 2026-11-01 | Тонмаппер ACES (сравнивали с AgX) | Глубже чёрный, сочнее туманности |
| 2026-11-01 | **far/near камеры ≤ 1e7** (иначе Godot 4.7 отсекает все меши). Дальние тела — **scaled space** (рисуются ближе и меньше с тем же угловым размером), см. `Star.max_render_distance` | float32-математика фрустума в Godot |
| 2026-11-01 | Атмосфера/облака/океан — «внутренняя сторона завышенной сферы, без depth test, аналитическое пересечение + стоп по depth» | Работает и из космоса, и изнутри; бесплатная дымка над рельефом; совместимо с floating origin |
| 2026-11-01 | Солнце в шейдерах — глобальные uniform `sun_direction`, `sun_color`, `sun_intensity` (`SunGlobals`) | Один источник для всех тел |
| 2026-11-01 | Чанки рельефа 65×65 + морфинг рёбер в вершинном шейдере + юбки | В 3 раза меньше чанков/draw calls, без трещин |
| 2026-11-01 | Тела системы статичны (без орбитального движения и вращения) в прототипе | Посадка/полёт проще; можно добавить позже |
| 2026-11-01 | Ввод регистрируется в коде (`Controls`), не в project.godot | Нет конфликтов между агентами, F1 из одного места |
| 2026-11-01 | Скриншоты снимаются с `--fixed-fps 60` (облако и ПК) | Детерминированное TIME: кадры CPU и GPU совпадают по анимации облаков/звезды |
| 2026-11-01 | Флора — MultiMesh-патчи по детерминированной сетке куб-сферы, биомы = CPU-копия формул шейдера рельефа (`ScatterBiome`) | Одинаковый результат при любом порядке загрузки, лес там, где он нарисован |
| 2026-11-01 | **Scaled space**: визуал группы тел (планета + луны) масштабируется относительно камеры одним k = compress(b)/b (b — дальний край группы), compress — одна монотонная функция (тождество до F_lin, мягкая степенная выше); тело-фокус у поверхности не масштабируется. Узел тела остаётся в истинной позиции | Тот же кадр, сжатая глубина; порядок перекрытия между группами сохраняется, внутри группы — точный; гравитация/коллизии/API не затронуты |
| 2026-11-01 | **far = near × 4e6** (замер: при 1e7 меш на 0.9·far исчезает) | Запас к пределу float32 фрустума Godot 4.7 |
| 2026-11-01 | Свет: главный `DirectionalLight3D` с тенями (звезда → камера) для слоя 1 + группы-фокуса; по одному свету без теней на каждую другую группу (render layers); `body_sun_dir` в шейдерах слоёв | Правильная фаза каждого тела с любой точки системы (иначе все тела освещены «из-за камеры») |
| 2026-11-01 | Рельеф: свой `light()` — солнце ослабляется атмосферой (по вершинам) и тенями облаков, амбиент неба из модели атмосферы | Закаты/дымка на рельефе согласованы с атмосферой, облака дают тени |
| 2026-11-01 | Общий DirectionalLight тонируется пропусканием атмосферы и тенью тел в точке камеры (корабль, игрок, флора — стандартные материалы), рельеф фокус-группы делит обратно (`light_unattenuate`); амбиент окружения = небо модели атмосферы, рельеф использует только свой (`ambient_light_disabled`) | Один источник света с тенями, закаты/ночь на корабле и траве согласованы с рельефом без второго теневого света |
| 2026-11-01 | Физическая интерполяция движка выключена; вместо неё экстраполяция на стороне рендера в пределах физического тика (визуал корабля, камеры погони/кабины, голова/модель пешехода) | Сдвиги floating origin телепортируют тела на 2 км в физическом тике — интерполяция рисует промежуточный кадр; экстраполяция не трогает физику и origin |
| 2026-11-01 | Кратеры/вулканы гаснут до нуля у границы ячейки Вороного (`RETURN_DISTANCE2_SUB` той же ячеистой сетки) | Непрерывное поле высот без обхода соседних ячеек (27 оценок на сэмпл в GDScript — слишком дорого) |
| 2026-11-01 | Тела без поверхности (газовый гигант, звезда) — «пол давления/жара»: выталкивание + жёсткая граница вместо шасси | Нельзя «сесть» на облака или провалиться бесконечно |
| 2026-11-01 | Волна 4 — только красота/доводка, оптимизация отложена; локальная GPU-сессия не используется (не отчитывается сама) | Решение пользователя |
| 2026-11-01 | **Звук — полностью процедурный**: банк `AudioStreamWAV` синтезируется в коде (`Synth`) на рабочем потоке во время загрузки; шины и эффекты создаются в рантайме (без bus-layout); 2D-плееры, громкость/фильтры ведутся из состояния корабля/игрока | Нет файлов и загрузок, всё правится параметрами; AudioStreamGenerator в GDScript дорог на 44 кГц, а готовые петли + pitch_scale + фильтры шин почти бесплатны |
| 2026-11-01 | Музыка — генеративные пэды из одной синтезированной ноты, транспонируемой `pitch_scale` в аккорды, кроссфейды, колокольчики из пентатоники; настроение по состоянию (космос/планета/пешком) | Бесконечно, не повторяется дословно, ~1 МБ PCM |
| 2026-11-01 | Загрузка по кадрам: тот же порядок, что `build_terrain_now`, но блокирующий сбор чанков порциями ~70 мс между кадрами (экран загрузки живой, скорость как у синхронной); съёмка/демо — синхронно | Неблокирующий сбор «по кадру» оказался в 3–4 раза медленнее (накладные расходы кадра) |
| 2026-11-01 | Ограничитель снижения FA масштабируется локальной g (`a = clamp(0.62 g, 1.3, 6)`) и считается от ближайшей опоры; на неровном грунте корпус доворачивается на плоскость под опорами | Мягкие касания на лунах (≤ 2 м/с), без «зависания» на двух опорах |
| 2026-11-02 | Экранные эффекты, которые выводят копию экрана с `ALPHA = 1` (heat haze), рисуются **первыми** среди прозрачных (`MATERIAL_RENDER_PRIORITY_MIN`) | В 3D копия экрана снимается после непрозрачного прохода и не содержит прозрачных слоёв планет; нарисованный позже эффект стирал атмосферу/облака/океан в своей области |
