# Оптимизация FPS перед v0.1 (локально, RTX 3060)

Дата: 2026-11-02. Машина: RTX 3060, Ryzen 7 5700X, Windows 11, 1920×1080 fullscreen, vsync off.
Инструмент: `tools/dev/gpu_bench.ps1` / `gpu_ab.ps1` (GPU-время вьюпорта, 300 кадров после 300 прогрева).
Шум замеров между запусками ±0,5 мс (если параллельно открыта игра — больше).

## 1. Итог (настройки по умолчанию)

| вид | до (волна 4) FPS / GPU мс | после FPS / GPU мс |
|---|---|---|
| `start` (луг, корабль, флора) | 41,4 / 24,05 | **51,6 / 19,27** |
| `terra_ground` | 51,6 / 19,29 | **62,0 / 16,02** |
| `terra_low` | 55,4 / 17,96 | **65,3 / 15,20** |
| `terra_sunset_ground` | 48,7 / 20,42 | **58,6 / 16,97** |
| `terra_orbit` | 79,1 / 12,55 | **89,4 / 11,09** |
| `orbit_chase` | 81,2 / 12,22 | **88,7 / 11,18** |
| `terra_entry` | 107,2 / 9,23 | 111,5 / 8,87 |
| `aurelion_rings` / `system_overview` | 210 / 207 | 222 / 214 |

С опциями меню «Графика» (Esc):

| вид | MSAA 2x (по умолч.) | TAA | TAA + «Среднее» небо |
|---|---|---|---|
| `start` | 51,6 | 54,2 | **58,9** |

Цель «60 FPS на RTX 2060» (≈ 80 на 3060) у земли по умолчанию **не достигнута**: на 2060 ожидаемо ~38–48 FPS
у земли, с TAA + «Среднее» ~45–55. Дальше нужны изменения шейдеров (§4).

## 2. Что изменено (по умолчанию, визуально без заметной разницы на кадрах)

| правка | где | выигрыш (start / ground) |
|---|---|---|
| **MSAA 4x → 2x**. В `project.godot` стояло `msaa_3d=2` — это **4x** (у Godot 1 = 2x), а не 2x, как писал perf_gpu | `project.godot` | −1,6 / −1,1 мс |
| Атлас направленных теней 8192 → 4096 | `project.godot` | −0,7 мс |
| Фильтр мягких теней Soft Low → Soft Very Low | `project.godot` | −1,2 мс |
| Без смешивания сплитов теней (`directional_shadow_blend_splits`) | `SolarSystem._build_lights` | −0,9 / −0,5 мс (low −1,6) |
| Анизотропия 16x → 8x | `project.godot` | −0,6 / −0,6 мс (low −1,2) |

Кадры до/после (start, terra_ground, terra_low, sunset, orbit) сравнены попиксельно-визуально: трава, тени
корабля и деревьев, рельеф с высоты — без заметной разницы; MSAA 2x на траве чуть менее мягкий, чем 4x.

## 3. Меню «Графика» (новое)

`src/core/graphics_settings.gd` (`GraphicsSettings`), раздел в меню паузы, сохраняется в `user://settings.cfg [graphics]`:
- **Сглаживание**: MSAA 4x / **MSAA 2x** (по умолчанию) / TAA. TAA: −1 мс к MSAA 2x, мягче трава и зерно облаков,
  но в движении у земли картинка заметно мягче (видео взлёта: лес и трава размываются) — поэтому не по умолчанию.
- **Облака и атмосфера**: Высокое (quality 1) / Среднее (quality 0): −1,5…−2,5 мс у земли; на стоп-кадрах у земли
  разница почти не видна.
- Съёмка и бенчмарки (`--shot` / `--cam`) настройки пользователя не читают — кадры сравнимы.

## 4. Куда уходит кадр (start, до правок, вычитанием)

| что | мс |
|---|---|
| Рельеф целиком (геометрия + шейдер + тени рельефа) | ~8,5 |
| — из них блок ближней детализации шейдера (камни, трещины, параллакс; < 90 м) | ~3,3 |
| — детальные нормали (triplanar normal maps) | ~3 |
| — тени рельефа | ~1,3 |
| Тени всего (`--no_shadows`) | ~5,4 |
| MSAA 4x | ~5,3 |
| Облака | ~4,6 |
| Атмосфера | ~3,5 |
| Анизотропия 16x на текстурах рельефа (всё → без) | ~2,8 |
| Флора (кроме теней) | ~0,9 |

Дальнейшие шаги (не сделаны, требуют работы с шейдерами и сверки картинки):
1. **Шейдер рельефа**: крупномасштабный шум (`nmac`, `nmac2`, `nbig`) перенести в вершинный шейдер; объединить
   выборки ближнего блока (`g4b` из мипа `g4`), реже — triplanar там, где одна ось доминирует. Ожидаемо −2…−4 мс у земли.
2. **TAA + временной джиттер** в облаках/атмосфере (`sd_ign` сейчас статичен по пикселю): TAA усредняет шум →
   можно вернуть атмосфере 12 шагов вместо 18 (`steps_mul` 1.5 у Terra) и уменьшить шаги облаков без зерна.
3. Анизотропию снимать только у карт нормалей рельефа (−1 мс): без неё вообще на голом грунте Selene вдали мылится.

Что пробовал и отказался: анизотропия выключена на всех текстурах рельефа (−2,8 мс, но грунт Selene вдали мылится);
FSR2 0.77 (62 FPS на старте, но мыло); FXAA выкл. при MSAA (0 мс); параллакс только < 18 м (0 мс);
`lod_factor` 0.7 (−0,5 мс, меньше деталей); тени рельефа выкл. (−1,3 мс, но горы без теней на закате).

## 5. Часть 2 — шейдер рельефа

Разбор фрагмента рельефа (старт, вариантами шейдера): весь фрагмент ≈ 5,2 мс (минимальный фрагмент: 13,7 мс кадр
против 18,9), у земли ≈ 4,3 мс. Цена размазана: убрать по одной части — по 0,2–0,3 мс каждая (макро-шум, второй
слой полосового шума, крупные нормали 2048/512, второй слой детальных нормалей, размытая выборка камней,
мелкий шум травы, тень облаков, нормали камней вблизи, упрощённый `light()`). Сделано (кадры неотличимы):

| правка | где | выигрыш |
|---|---|---|
| **Карты нормалей рельефа сжаты в BC5 (RGTC)**: сгенерированные `normal`/`rock` — `Image.compress(S3TC, NORMAL)`, импортируемые `ground_normal`, `ripples_normal`, `dunes_normal` — VRAM Compressed + normal map. Шейдеры восстанавливают z из xy (`rock_scatter` переведён на это) | `terrain_textures.gd`, `*.png.import`, `rock_scatter.gdshader` | −0,5…−0,8 мс у земли |
| **Порог triplanar**: веса проекций ниже 0,05 убираются непрерывно (вычитание + перенормировка) — на склонах чаще 1–2 проекции вместо 3, без шва. Синхронно в `ScatterBiome.tri_w` | `planet_terrain.gdshader`, `scatter_biome.gd` | старт −1,2 мс, у земли −0,4…−0,65, орбита −0,4 |

Итог после части 2 (RTX 3060, по умолчанию): **старт 57,0 FPS** (было 41,4 до оптимизации), у земли 66,7, низкий
полёт 70,8, закат 62,9, орбита 93,0, `orbit_chase` 92,7, `terra_entry` 118,7.
С TAA + «Среднее» небо: старт **64,6**, у земли 76,9, низкий полёт 80,9, закат 74,5.

Не делал (меняет картинку): раньше гасить камни/трещины вблизи (сейчас 35–90 м), меньше слоёв детальных нормалей,
макро-шум в вершины (с орбиты вершины редкие — теряется деталь), шейдер без анизотропии на голом грунте.
Следующий крупный резерв — облака (~4,6 мс) и атмосфера (~3,5 мс) у земли: TAA + временной джиттер (§4 п. 2).

## 6. Отладочные ключи (`scenes/main.gd`, для `gpu_ab.ps1`)

`--msaa=0..3`, `--fxaa=0..2`, `--taa=0|1`, `--scale3d=x --scale_mode=n`, `--shadow_size=N`, `--shadow_angular=deg`,
`--shadow_splits=1|2|4`, `--shadow_blend=0|1`, `--shadow_soft=0..5`, `--shadow_base=m`, `--terrain_shadows=0|1`,
`--lod=x`, `--hide=@<путь узла>`; `--section=graphics` для пресета `pause_menu`.
