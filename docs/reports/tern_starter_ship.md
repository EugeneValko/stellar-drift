# ST-7 «Tern» — стартовый корабль (hero-модель для рендера)

**Дата:** 2026-11-11 · **Статус:** модель, материалы и рендеры готовы; в движок НЕ интегрирована (по запросу — только рендер).

Запрос пользователя: показать максимум качества — внешняя модель стартового корабля уровня hero-ассета
(ориентир Star Citizen), с текстурами, тёмным остеклением, без интерьера, рендеры с нескольких ракурсов.
На прошлые концепты разрешено не ориентироваться — дизайн новый.

## Дизайн
Лёгкий экспедиционный корабль ST-7 «Tern» (крачка): 15,5 м в длину, размах 13,7 м, высота на шасси 5,2 м.
- Широкий несущий корпус с расклешёнными скулами и длинным тонированным фонарём.
- Крыло-«чайка»: центроплан поднимается к двигателям-подам на «запястье», консоли опущены к законцовкам с RCS.
- Два двигателя-пода с воздухозаборниками и центральными телами, регулируемые сопла с цветами побежалости.
- Кили с развалом на подах, дрифт-привод (кольцевая катушка) на транце между соплами.
- Три посадочные стойки с опорными плитами, створки ниш; подфюзеляжная оптическая турель, две пушки в обтекателях скул.
- Ливрея: тёплый белый / графит / сигнальный оранжевый, неокрашенные кромки и жаростойкие секции, номера и трафареты.

## Как это сделано (всё процедурно, Blender 5.2 headless + Cycles/OptiX)
| Файл | Назначение |
|---|---|
| `tools/blender/tern/kit.py` | Набор для hard-surface: лофты, токарные формы, трубы, фаски; **Panelizer** — режет гладкую оболочку на отдельные листы обшивки с настоящими зазорами, утопленными/приподнятыми люками и вырезами |
| `tools/blender/tern/mats.py` | Процедурные PBR-материалы в объектных координатах (без UV): общий узел `TernSurface` — сколы краски на кромках, грязь у стыков и в полостях, потёки, царапины, разнотон панелей, микрорельеф |
| `tools/blender/tern/design.py` | Мастер-размеры и гладкие тела (SubD-каркасы со складками) |
| `tools/blender/tern/ship.py` | Раскладка панелей, окраска, остекление, крепёж, декали, установка узлов, заглушка кабины |
| `tools/blender/tern/parts/*.py` | Узлы: `nozzle` (сопло, VTOL-сопло), `gear` (стойки, ниши, створки), `smallparts` (RCS, решётки, огни, антенны, лючки, крепёж…), `chin` (турель, пушка), `driftdrive`, `hangar` (ангар) |
| `tools/blender/tern/decals/` | `make_decals.py` (Pillow) → PNG-маски надписей и эмблемы |
| `tools/blender/tern/studio.py`, `post.py` | Настройка Cycles, студийный свет, авто-кадрирование, контактные листы; блум и виньетка в компоновщике |
| `tools/blender/tern/render.py` | Финальные кадры: `--scene=hangar` (9 ракурсов) и `--scene=studio` (проекции) |
| `tools/blender/tern/build.py`, `part_preview.py` | Быстрые превью корабля / отдельного узла |
| `tools/blender/tern/PARTS_GUIDE.md` | Правила для модулей узлов (оси, материалы, бюджет, как проверять) |

Запуск (≈ 10 с сборка, 1–2 мин на кадр 1080p на RTX 3060):
```
blender -b --factory-startup -P tools/blender/tern/render.py -- --scene=hangar --res=1920x1080 --samples=400 --blend
blender -b --factory-startup -P tools/blender/tern/render.py -- --scene=studio --shots=top,front,profile,back
blender -b --factory-startup -P tools/blender/tern/build.py -- --stage=ship --views=front34,rear34 --focus=x0,y0,z0,x1,y1,z1
```
`--blend` сохраняет сцену в `build/tern/tern_hangar.blend` (не коммитится).

## Что важно знать
- Это модель **для офлайн-рендера**: около 1,1 млн треугольников (ангар — ещё 0,24 млн), материалы — процедурные шейдеры Cycles.
  Для Godot нужен отдельный этап: упрощённая сетка/LOD, запекание материалов в PBR-карты, экспорт GLB, маркеры.
- Интерьера нет: за тонированным стеклом — тёмная «ванна» с силуэтами кресел и приборной панели.
- Шасси только в выпущенном положении; створки открыты. Полётной конфигурации (убранное шасси) нет.
- Узлы делали параллельные агенты по общему гайду; стыковка проверена по рендерам, но детальной ревизии каждого
  узла вблизи не было.
- Известные слабые места: грязь/износ умеренные (корабль «ухоженный»); пол ангара местами даёт облачные блики;
  кили стыкуются с подами без зализов; панели на вогнутых скулах размечены проекцией и слегка искажены.

## Дальше (если пойдём в игру)
1. Игровая версия: ретопология корпуса (30–60 тыс. треугольников), LOD, запекание карт 4K (albedo/normal/ORM/emission).
2. Маркеры и анимируемые части по контракту `tools/blender/ship.py` (двигатели, RCS, шасси, трап, фонарь).
3. Семейство: тот же набор (`kit`, `mats`, `parts`) позволяет собрать другие корабли школы сменой таблиц в `design.py`.
