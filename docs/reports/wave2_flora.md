## 3. Система разброса (`PlanetScatter`)

```gdscript
var scatter := PlanetScatter.new()
planet.add_component(scatter)          # setup(config) + set_planet(planet); пресет по имени файла конфига
# опционально: scatter.focus_node = player   (по умолчанию — planet.terrain.focus, т.е. тот же фокус, что у LOD)
# scatter.set_focus(local_pos) / clear_focus_override(); scatter.build_until_stable()  (загрузка/скриншоты)
# scatter.get_stats() -> instances, tris, patches, bodies, по слоям
```

- **Сетка ячеек** — равноугольная (equi-angular) куб-сфера, независимая от квадродерева рельефа: ячейки почти
  одинаковой площади, отображение направление ↔ ячейка аналитическое в обе стороны. Ячейка = (грань, i, j).
- **Детерминизм**: содержимое ячейки зависит только от (seed планеты, seed слоя, ячейка) — `RandomNumberGenerator`
  с seed = hash. Одни и те же деревья в ближнем и дальнем кольце, при любом порядке загрузки.
- **Размещение**: в ячейке сэмплируется сетка высот `TerrainGenerator.sample()` (та же функция, что у мешей рельефа,
  потокобезопасная), нормали — центральными разностями; биом (`ScatterBiome`) считается на прореженной сетке (~24 м),
  веса правил интерполируются. Кандидаты — стратифицированный джиттер; вероятность = density × Π мягких диапазонов
  атрибутов × шум кластеризации (рощи, поляны цветов). Высота — билинейно по сетке или точно (`exact_height`,
  для деревьев/камней). Сетка высот/биома одной ячейки **общая для всех слоёв** с той же сеткой (кэш с mutex).
- **Биом = как у рельефа**: `ScatterBiome` повторяет формулы шейдера рельефа (влажность + «макро» шум + шум 2 км
  по той же текстуре `TerrainTextures` на CPU, снеговая линия/полярные шапки, скалы по уклону/маске гор,
  пустыни, пляж, лава, лёд Glacia). Поэтому лес растёт там, где рельеф окрашен в «лес», нет травы на скалах/снегу.
  Атрибуты правил: `height` (над уровнем моря), `slope`, `moist`, `forest`, `snow`, `rock`, `desert`, `beach`,
  `lava`, `ice`, `lat`.
- **Ориентация**: локальная +Y экземпляра = вверх сферы (выглядит правильно в любой точке планеты), опционально
  смешивание к нормали рельефа (`align_to_normal`), случайный поворот и наклон, утапливание `sink`.
- **Кольца и патчи**: ближнее кольцо — по одному `MultiMeshInstance3D` на ячейку, LOD меша по расстоянию до патча
  (с гистерезисом), тени только в пределах `shadow_distance`. Дальнее кольцо (деревья 0.7–3 км) — патчи
  8×8 ячеек с мешем-оболочкой (~50 треуг.). Переход ближнее↔дальнее — дизер-кросс-фейд по экземплярам
  (`instance uniform fade_range`), скрытые экземпляры схлопываются в вершинном шейдере (не растеризуются).
  Трава: уход в землю (масштаб→0) у границы и прореживание с 20 м (остаётся 25 %).
- **Потоки**: генерация ячеек — `WorkerThreadPool` (`max_jobs`=2), главный поток только создаёт MultiMesh из
  готового буфера (`multimesh.buffer = PackedFloat32Array`, ≤ 8 патчей и ≤ 2.5 мс за кадр). Сканирование колец —
  по одному кольцу за кадр (round robin), перебор ячеек напрямую по грани (у рёбер куба — выборкой диска).
- **Floating origin**: патчи — дети узла `PlanetScatter` (дети планеты), позиции планетарные; трансформы
  экземпляров — относительно начала патча (малые числа, точность float32). Сдвиг/поворот планеты бесплатен.
  Ветер берёт координаты из `patch_origin` (mod 4096 м) — порывы непрерывны и не скачут при сдвиге origin.
- **Высота**: выше `max_altitude` (Terra 3.6 км) всё снимается; рельеф и цвет «леса» видны и так.

## 4. Коллизии
Для деревьев (капсулы по стволу), валунов (сферы) и групп камней/базальта (выпуклая оболочка LOD1) у патчей
ближе `collision_distance` (50–70 м) создаётся один `StaticBody3D` (слой 1) с shape owners (без узлов
`CollisionShape3D` — дешевле), ≤ 1 тело за кадр; удаляется дальше 1.3× дистанции. Данные — CPU-копия буфера
(без чтения из GPU).

## 5. Производительность

CPU контейнера: 4 ядра, во время замеров загрузка 10–13 (ещё 3 агента рендерят) — числа сильно завышены.

| Метрика | Значение |
|---|---|
| Полная синхронная постройка Terra Nova у земли (луг) | ~4.8 с (≈11 000 ячеек, 15 слоёв, деревья до 3 км) |
| Одна ячейка на воркере | 0.05–0.14 мс (Terra), до 1.3 мс (Glacia/Selene — большие ячейки, точные высоты) |
| Ignis / Glacia / Selene полная постройка | 0.55–0.95 с |
| Главный поток при ходьбе 5 м/с | среднее 0.4 мс/кадр; пики 9–14 мс (скан кольца / тело коллизии / загрузка дальнего патча 3000 экз.) под 3× переподпиской CPU |
| Экземпляров (Terra: луг / опушка / 50 м / 300 м) | 169 / 175 / 135 / 183 тыс. (трава ~55–60 тыс., дальние деревья 50–100 тыс.) |
| Экземпляров (Ignis / Glacia / Selene) | 15 / 12.5 / 12 тыс. |
| Треугольников (верхняя оценка, все экземпляры) | ~8–12 млн; реально меньше: прореживание травы, скрытые кросс-фейдом экземпляры схлопнуты |
| Узлов-патчей (draw call'ов × 1–2 поверхности) | Terra 620–850, Ignis 290, Glacia 240, Selene 155 |
| Постройка в тестовой сцене (синхронно, под нагрузкой) | Terra 3–7.6 с, Ignis/Glacia/Selene 0.25–0.55 с |

Оценка для RTX 2060 / 1080p: геометрия ~5–8 млн видимых треуг. + тени деревьев до 320 м — порядка 5–8 мс GPU;
шейдеры листвы дешёвые (силуэт — 1 цикл до 6 эллипсов или пара fract), без прозрачности (alpha-scissor), трава —
без discard. Надо замерить на реальной машине. Ручки: `density`, `max_distance`, `far_start`, `lod_distances`,
`thin_start/keep`, `shadow_distance` у слоёв; `max_jobs`, `upload_budget_ms` у компонента.

## 6. Тестовая сцена
`scenes/test/scatter_test.tscn` — Terra Nova с атмосферой (`AtmosphereLayer`, пресет terra_nova), океаном,
`PlanetScatter`; свет солнца тонируется пропусканием атмосферы (`atmo.sun_transmittance`). Пресеты:
`meadow`, `forest_edge`, `hillside_view` (50 м), `rocky_slope`, `from_air` (300 м), `ignis_basalt`, `glacia_ice`,
`selene_boulders`, плюс `lineup` (все ассеты Terra в ряд). Место выбирается автоматически по биому (`ScatterBiome`).
```bash
tools/shot.sh scenes/test/scatter_test.tscn --shots=meadow,forest_edge,hillside_view,rocky_slope,from_air,ignis_basalt,glacia_ice,selene_boulders \
  --outdir=docs/screenshots/s2/flora --warmup=8 --stats
# --res=960x540 для превью; --site_seed=N другое место; --sun_elev/--sun_az; --no_atmo; --no_scatter
# --mu_<slot>__<param>=value — подмена параметра материала (отладка), напр. --mu_leaves__debug_mode=3
godot --headless -s tools/dev/scatter_bench.gd -- want=meadow alt=2 speed=5 frames=600 [only=grass,spirepine]
godot --headless -s tools/dev/make_scatter_presets.gd          # пересобрать presets/*.tres
blender -b -P tools/blender/flora_terra.py -- assets/models/flora_terra.glb   # (rocks.py, crystals.py аналогично)
```
На CPU-рендере один кадр 1080p со всем этим — несколько минут; используйте `SHOT_TIMEOUT=3000+`.

## 7. Что хорошо / что слабо

Хорошо:
- Луг/опушка: густая трава с ветром, цветы и «лампочки», пурпурные кусты, три силуэта деревьев читаются издалека.
- С воздуха (300 м): смешанный лес до горизонта без шва между ближним и дальним кольцом; рощи и поляны
  следуют биому рельефа.
- Glacia: ледяные осколки и валуны на снежной равнине; Selene: валуны с длинными тенями, галька.
- Всё детерминировано, работает в любой точке сферы, генерация не блокирует главный поток.

Слабо / что дальше:
- Хвойные — стилизованные «карточные» ярусы; вблизи видна повторяемость ветвей (один скелет на вид). Нужны 2–3
  варианта скелета на вид и/или octahedral-импосторы вместо LOD2-оболочек.
- Листва — процедурный силуэт без текстур: аккуратно, но «мультяшно»; можно запекать атлас листьев в Blender.
- Draw call'ов много (~600+ патчей); следующий шаг — объединять мелкие слои в одну MultiMesh по патчу или
  укрупнить ячейки ближнего кольца деревьев с пер-экземплярным LOD-кросс-фейдом.
- Высота экземпляров — функция высоты, а не меш LOD рельефа: на дальних (грубых) чанках деревья могут слегка
  висеть/тонуть (компенсировано `sink`), на 2+ км незаметно.
- Пики главного потока при движении (скан колец, тело коллизии) — под переподпиской CPU до 10+ мс; надо
  перемерить на реальной машине, при необходимости — бюджет по времени на скан/тело.
- Ignis: камера в лавовом каньоне — стена каньона со стратами занимает верх кадра, базальт против света почти
  чёрный и «кубичный» (верхние грани столбов без фаски/скола); стоит добавить фаски и сколы в `rocks.py`.
- Валуны Terra на крутых склонах издалека выглядят «точками»; у плит на уклонах иногда виден край над землёй.
