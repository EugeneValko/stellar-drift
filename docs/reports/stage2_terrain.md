# Этап 2a — система рельефа планет (отчёт)

Ветка: `worktree-agent-ae8880ba5a545a7ba`. Скриншоты: `docs/screenshots/s2/terrain/*.png` (1920x1080).

## Что сделано

| Файл | Назначение |
|---|---|
| `src/planets/planet_config.gd` | `PlanetConfig` (Resource): тип, радиус, seed, все параметры рельефа, климат, палитра, флаги атмосферы/океана/облаков, подсказки для компонентов |

## Архитектура

### Cube-sphere и квадродерево
- 6 граней куба, точка грани `n + u·U + v·V` (u,v ∈ [-1,1]) → **spherified cube** (равномерная площадь ячеек).
- Каждая грань — квадродерево `ChunkNode`. Чанк — сетка **65×65 вершин** (64×64 квада) + юбки.
  (В ARCHITECTURE.md было 33×33; 65×65 при `lod_factor=1` даёт ту же плотность треугольников на экране,
  но в ~3 раза меньше чанков/draw calls.)
- Глубина: `max_level` считается из радиуса так, чтобы шаг вершин на самом мелком уровне был ≤ `finest_quad` (0.4 м):
  Terra Nova — 12 уровней (0.36 м), Ignis — 11, Selene — 10, Nyx — 9.
- **Критерий разбиения**: расстояние от фокуса до «коробки» чанка (горизонталь и вертикаль считаются раздельно,
  чтобы высокие горные чанки не переразбивались) `< edge · lod_factor` (+10 % гистерезис).
  Перед постройкой высотный диапазон чанка оценивается по 5 сэмплам, после — уточняется по реальному min/max.
- **Горизонт**: чанки целиком за горизонтом (окклюдер — сфера через грунт под фокусом минус 250 м, с учётом уровня моря) не дробятся.
- `min_level = 2` — с орбиты планета минимум из 96 чанков (силуэт гор виден).
- Пока дети строятся, показывается родитель; при слиянии дети удаляются только когда родитель готов — дыр нет.

### Потоки и бюджет кадра
- Меши строятся в `WorkerThreadPool` (по умолчанию `cores − 2` задач одновременно). Поток пишет только в свой `ChunkJob`.
- Там же строится BVH коллизии (`ConcavePolygonShape3D.set_faces`, половинное разрешение: шаг 0.72 м).
- Главный поток: загрузка ≤ 6 мешей/кадр с бюджетом 3 мс, ≤ 1 тела коллизии/кадр, ≤ 8 разбиений/кадр;
  пересчёт дерева только при сдвиге фокуса > 2 % высоты или при приходе новых чанков.
- `build_until_stable()` — синхронная достройка (загрузочный экран / скриншоты).

### Швы между уровнями
- **Морфинг рёбер**: для нечётных вершин на рёбрах в `CUSTOM2` записан сдвиг к середине соседних чётных вершин.
  Дерево вычисляет для каждого видимого чанка маску «сосед грубее» (в т. ч. через рёбра граней куба) и передаёт её
  `instance uniform coarse_edges`; вершинный шейдер подтягивает вершины → T-образных трещин нет при разнице в 1 уровень.
- **Юбки** (2 шага сетки вниз) — страховка для разницы в 2+ уровня.
- Все октавы шума считаются на всех уровнях (без пропуска мелких октав для грубых чанков) — иначе соседние уровни
  расходились на метры и юбки становились видны (тёмная «пила» из-за теней).
- Нормали гладкие через границы чанков: сэмплируется сетка 67×67 (кольцо-«фартук»), нормали — центральные разности.

### Данные вершин → шейдер
| Канал | Содержимое |
|---|---|
| `VERTEX` | позиция относительно origin чанка (origin считается в float64; MeshInstance3D стоит в origin) |
| `NORMAL` | гладкая нормаль |
| `COLOR` (8 бит) | r — выход скалы (маска гор), g — лава, b — выбросы кратеров, a — кривизна (0.5 = плоско) |
| `CUSTOM0` | xyz — «детальные» координаты = позиция mod 4096 м (непрерывны внутри чанка, периодичны между чанками), w — высота над радиусом, м |
| `CUSTOM1` | xyz — единичное направление от центра, w — влажность |
| `CUSTOM2` | xyz — сдвиг морфинга, w — номер ребра + 1 |

Точность: все текстуры детализации тайлятся с периодом-степенью двойки ≤ 2048 м, а координаты берутся из `CUSTOM0`
(маленькие числа) — нет потери float-точности на расстоянии 60 км от центра планеты. Макро-вариация с орбиты
берётся по направлению (`|dir| = 1`). Всё в пространстве планеты → совместимо с floating origin (в тестовой сцене
камера стоит в (0,0,0), а планета сдвинута на `−camera_local` — ровно как будет делать Universe).

### Функция высоты (`TerrainGenerator.sample`)
FastNoiseLite (нативный), ~4–7 мкс на точку:
1. Континенты: fbm с domain warp → профиль суши (равнины) / шельф / океанские впадины.
2. Горные хребты: ridged-fbm (со своим warp) на «плато», маска хребтов (низкочастотный шум), только вглубь суши;
   `mountain_sharpness` — степень; эрозионно-подобные «овраги» (второй ridged-шум, модулированный высотой хребта:
   гребни изрезаны, долины гладкие).
3. Холмы, вулканы (cellular: щитовые конусы с кальдерами и лавой), каньоны (|warped noise| с плоским дном, лава на дне),
   террасы/страты (меза), кратеры (3–5 слоёв cellular: чаша, плоское дно, вал, центральная горка, маска выбросов),
   «моря» на лунах, плоские ледяные/лавовые равнины (`floor_level`).
4. Мелкий рельеф: шероховатость (~150 м) и микрорельеф (~16 м, ±0.5 м) — на всех уровнях.

Важно: у FastNoiseLite domain warp по умолчанию имеет lacunarity 6 и 5 октав — это дало «иголки» с шумом ±200 м на 20 м.
Теперь warp настраивается через `TerrainGenerator._warp()` (2–3 октавы, lacunarity 2).

### Шейдер `planet_terrain.gdshader`
- Биомы: уровень моря/пляж (пляж гаснет с расстояния и при субпиксельной ширине — без «контурных линий» с орбиты),
  трава/сухая трава/лес/пустыня по влажности (вершинная влажность + макро-шум), альпийский пояс (скала/осыпь),
  снег по высоте и широте с учётом уклона и кривизны (копится в кулуарах, сходит с гребней и стен), полярные шапки,
  скала по уклону и маске гор, страты в скалах, лёд (Glacia), выбросы кратеров (луны).
- Детализация: «лестница» масштабов по расстоянию (тайлы 2→8→32→128→512 м с плавным переходом) — нет видимого
  тайлинга ни вблизи, ни издалека; трипланар в пространстве планеты; детальные нормали (whiteout blend) разные для
  почвы и скал + крупные нормали 512/2048 м для рельефа с высоты; вблизи (< 120 м) — пучки травы и камешки.
- Лава: светящиеся трещины корки (cellular) + сплошные потоки в ядре маски, emission × `lava_intensity` → glow.
- Параметры палитры и пороги берутся из `PlanetConfig` (`Planet.create_terrain_material`).

## API

```gdscript
# Planet (src/planets/planet.gd) — корень планеты
@export var config: PlanetConfig
@export var component_scenes: Array[PackedScene]   # инстанцируются и добавляются через add_component()
@export var auto_focus_camera := true               # иначе вызывать set_focus()
func build() -> void                                # (пере)строить по config
func add_component(node: Node) -> Node              # node.setup(config) и node.set_planet(self), если есть
func get_component(name) / get_components()
func set_focus(local_pos: Vector3) / set_focus_global(world_pos: Vector3)
func get_height(dir: Vector3) -> float              # м над config.radius
func get_surface_point(dir: Vector3) -> Vector3     # в пространстве планеты
func get_altitude_global(world_pos: Vector3) -> float
func get_shader_params() -> Dictionary              # planet_radius, ocean_radius, ... для других шейдеров
signal component_added(node), terrain_ready
var terrain: PlanetTerrain

# PlanetTerrain
func set_focus(local_pos: Vector3)
func get_height(dir) / get_surface_point(dir) / get_altitude(local_pos)
func build_until_stable(max_seconds := 120.0)
func is_idle() -> bool
func get_stats() -> Dictionary
@export lod_factor, min_level, finest_quad, max_uploads_per_frame, upload_budget_ms, max_splits_per_frame,
        max_jobs, collision_levels, collision_radius, cast_shadows, horizon_margin

# PlanetConfig
func get_ocean_radius() -> float   # radius + sea_level, 0 если океана нет
func has_ocean_surface() -> bool   # has_ocean && sea_level != 0
```

Океан: сфера радиуса `config.get_ocean_radius()` с центром в узле Planet (Terra Nova: 60 000 + 1 500 м).
Высоты рельефа отсчитываются от `radius`; для океанских планет суша — `h > sea_level`.

## Производительность (CPU этого контейнера: 4 ядра, делятся с 3 другими агентами — числа завышены)

| Метрика | Значение |
|---|---|
| `get_height()` | 4–7 мкс |
| Сборка чанка 65×65 (+фартук, нормали, морфинг) в потоке | 20–30 мс (Terra/Glacia), ~30 мс Ignis; макс. ~60 мс |
| То же + коллизия (BVH половинного разрешения) | +~3–5 мс в потоке |
| Загрузка меша на главном потоке (`add_surface_from_arrays`) | 0.6–0.8 мс |
| Создание тела коллизии | ~1 мс (не более 1 за кадр) |
| Обход дерева (~500 узлов) | ~1.5 мс, только когда фокус сдвинулся > 2 % высоты |
| Простой (камера стоит) | ~0.02 мс/кадр |
| Спуск с орбиты (150 км) до 2 м за 10 с (`perf_descent.gd`) | главный поток: avg 0.8 мс, p50 0.02 мс, p95 4.3 мс; LOD готов через 1 кадр после «касания» |
| Число чанков (видимых) | орбита 96 · 20 км ~120 · 500 м ~250 · 2 м ~380–430 |
| Полная синхронная постройка в точке (3 потока) | орбита 3.5 с (126 чанков) · 500 м 9–11 с · 2 м 7–14 с |

Редкие пики p99 8–16 мс в headless-тесте — это вытеснение главного потока (рабочие потоки + чужие процессы на 4 ядрах);
изолированно каждая операция ≤ 1 мс. GPU: у поверхности ~3.5 млн треугольников, ~400 draw call (+ тени);
фрагментный шейдер ~40 выборок текстур — для RTX 2060 в 1080p это нормально, но на реальной машине надо замерить.

## Как смотреть

```bash
tools/shot.sh scenes/test/planet_test.tscn --shots=orbit,high_alt,low_flight,surface,surface_sunset,moon_orbit,ignis_low,glacia_low \
  --outdir=/tmp/terrain --res=960x540 --warmup=6
# доп. пресеты: ignis_orbit, glacia_orbit, vex_orbit, nyx_orbit, selene_surface; --planet=<preset> подменяет планету; --ocean=0
godot --headless -s tools/dev/bench_terrain.gd -- res://src/planets/presets/glacia.tres
godot --headless -s tools/dev/lod_stats.gd -- res://src/planets/presets/terra_nova.tres 2 peak
godot --headless -s tools/dev/perf_descent.gd -- res://src/planets/presets/terra_nova.tres 600
```
Пресеты сцены синхронно достраивают LOD (`build_until_stable`), поэтому `--warmup` может быть маленьким.
Место съёмки выбирается автоматически: самая высокая (и для Terra — влажная) вершина, долина перед хребтом,
лавовый каньон для Ignis.

## Что хорошо / что слабо

Хорошо:
- С орбиты: континенты, шельф, полярные шапки, хребты со снегом; Ignis — сеть светящихся лавовых каньонов;
  Vex — серно-жёлтая луна с лавовыми трещинами; Selene — кратеры разных размеров с валами и выбросами.
- Средние высоты (500 м – 20 км): хребты с оврагами, альпийский пояс, снег в кулуарах, страты в стенах каньонов Ignis.
- Нет трещин между уровнями LOD, нет видимого тайлинга текстур, нет дрожания (floating origin в тесте).

Слабо / известные проблемы:
- **Небо чёрное, нет атмосферы/воздушной перспективы** — дальние горы выглядят «лунно»; основная красота придёт с атмосферой.
- Вблизи земли (2 м) трава — это только текстура; нужна растительность (MultiMesh — следующий этап) и камни.
  На lavapipe нет анизотропной фильтрации — земля под острым углом размыта; на реальном GPU должно быть резче.
- Сильная экзагерация рельефа: с орбиты Glacia/луны имеют «комковатый» силуэт (так задумано, можно уменьшить `mountain_height`).
- Трипланар в осях планеты на наклонных к осям склонах слегка «тянет» шум (полосы на траве под углом).
- Разница LOD в 2+ уровня (редко) закрывается только юбками.
- Обход дерева на GDScript ~1.5 мс при движении; если понадобится — перенести `PlanetTerrain` в C++/GDExtension.
- В оконном прогоне (Vulkan/Xvfb) внутри `build_until_stable` один раз зафиксировано 220 мс на создание тела коллизии
  (в headless — ~1 мс на тело); похоже на первичную инициализацию физики. В игре тела создаются по одному за кадр,
  но это надо проверить на Windows-сборке.
- `surface_sunset` тёмный: без неба нет рассеянного света (ambient в тестовой сцене — заглушка).

## Нужные изменения общих файлов (не делал)
- `project.godot`: изменений не требуется. Опционально `rendering/limits/global_shader_variables/buffer_size` —
  `instance uniform` по 1 int на чанк, дефолта (65536) хватает с запасом.
- `docs/ARCHITECTURE.md`: заменить «сетка ~33×33» на «65×65 + морфинг рёбер + юбки».
- `docs/DECISIONS.md` (предлагаемые строки):
  - Чанк 65×65, `lod_factor=1`: меньше draw call при той же экранной плотности.
  - Детальные координаты = позиция mod 4096 м в `CUSTOM0` (точность float на больших радиусах).
  - Морфинг нечётных вершин рёбер по маске соседей вместо перестройки мешей.
  - Все октавы шума на всех LOD (иначе разрыв уровней на метры).
- Компоненты атмосферы/океана/облаков подключать через `Planet.add_component()` / `component_scenes`;
  метод `setup(config: PlanetConfig)` и (опц.) `set_planet(planet: Planet)`.
