## Полётная модель
- **RigidBody3D** со стандартным интегратором; управление — изменения скорости в `_integrate_forces`
  (масса 22 т нужна только для контактов). Гравитация — `Universe.get_gravity`, плотность — `Universe.get_atmosphere_density`.
- **Flight assist (Z)**: целевая скорость в осях корабля = (A/D·strafe, Space/Ctrl·strafe, −throttle·cap);
  ошибка/τ + компенсация гравитации и сопротивления, ограничение по осям (маршевый / реверс / боковые).
  Итог: дрейф гасится, вектор скорости «держится» за носом. Без FA — чистый Ньютон (W/S/A/D/Space/Ctrl = тяга).
- **Аэродинамика (упрощённо)**: квадратичное сопротивление `ρ·v²·k` + «флюгер» (боковая скорость гасится
  пропорционально ρ — корабль в атмосфере летит как самолёт, без FA особенно заметно).
- **Повороты**: мышь = виртуальный джойстик (накопление смещения, мягкий возврат к центру `mouse_return`,
  мёртвая зона + экспонента), Q/E — крен. Угловая скорость догоняет цель с ограничением углового ускорения
  (`rate × 4`) — плавно и «тяжело». Скорости поворота зависят от режима (варп — вязкий).
- **Автовыравнивание**: в HOVER (или низко и медленно) при FA нос/крен тянутся к локальной вертикали
  (`Universe.get_up`), ввод игрока имеет приоритет.
- **Ограничитель у земли (FA)**: скорость снижения ≤ √(2·6·h)+1.2 м/с — в планету не врезаться, касание ~1–3 м/с.
- **Нагрев**: `heat → clamp(√ρ·(v/1500)²·0.8 − 0.1)` с инерцией (растёт ~1 с, остывает ~2 с).
  Конденсация — при 180–900 м/с в плотном воздухе (ρ > 0.2).

## Режимы скорости
| # | Режим | Макс. | Ускорение | Особенности |
|---|---|---|---|---|
| 1 | HOVER | 50 м/с (×1.6 Shift) | 24 м/с² | W/S — прямое управление (без «круиза»), автовыравнивание, авто-шасси |
| 2 | ATMOSPHERE | 600 м/с | 42 + 0.3·v | газ-«круиз» W/S |
| 3 | SPACE | 5 км/с | 80 + 0.6·v | в атмосфере потолок падает до 800 м/с по ρ → «торможение о воздух» с нагревом |
| 4 | CRUISE | 300 км/с | 600 + 0.85·v (экспонента) | запрещён в атмосфере и ниже 10 км; потолок = 0.5·высота (авто-торможение у тел) |
| 5 | WARP | 30 000 км/с | 3·10⁴ + 1.3·v | раскрутка 2 с, запрещён ближе 600 км к поверхности (mass lock), потолок = 1.0·(расстояние − 20 км), авто-выход в CRUISE при потолке < 300 км/с |

Tab — следующий допустимый режим, 1–5 — прямой выбор (с сообщением об отказе: «CRUISE BLOCKED: ATMOSPHERE»,
«WARP: MASS LOCKED»). Переход вниз — плавное торможение (экспонента 2.2/с). X — полная остановка.
Подсказка режима в `get_hud_data()["mode_suggest"]`.

## Высокие скорости и floating origin
- Выше **6 км/с** тело «паркуется» (скорость в физике 0), а корабль двигается сам: смещение `v·dt` применяется
  в `_physics_process` и **в том же тике** вызывается `Universe.shift_origin(...)` — корабль всегда в (0,0,0),
  ни один кадр не рисуется далеко от начала координат (нет дрожания на 500 км/кадр в варпе).
- Отрезок перемещения проверяется против сфер тел (радиус×1.15 + 10 км): если пересекает — остановка у границы,
  сброс в SPACE («EMERGENCY DROP»). Плюс потолки скорости ∝ высоте → туннелирования нет.
- В обычном режиме Universe сдвигает мир при удалении > 2 км; RigidBody получает новый `global_position`,
  скорость не теряется. `Ship.teleport(xf, v, frozen)` — надёжная телепортация (повторно применяет трансформ
  в `_integrate_forces`: без этого физсервер иногда возвращал старую ориентацию при одновременной заморозке).

## Посадка
- **Шасси = аналитическая подвеска**: 3 опоры (пружина 6·10⁵ Н/м + демпфер, ход 0.55 м, кулоново трение μ=1.3)
  считаются по функции высоты планеты (`get_altitude_global`) и уровню океана — работает даже когда
  коллизионные чанки ещё не построены, садиться можно и на воду. Коллайдеры корпуса (капсула, гондолы, крыло,
  хребет) — для ударов о рельеф; последний рубеж — аналитический «клэмп» корпуса по 9 точкам.
- **Landed**: все 3 опоры в контакте, |v| < 0.8 м/с, без ввода 0.5 с → «LANDING CLAMPS» (`freeze`) — корабль
  абсолютно неподвижен на склоне. Взлёт: Space / газ / автопилот → `freeze=false` + 2.5 м/с вверх.
- G — шасси (нельзя убрать с весом на опорах). Авто: выпуск в HOVER ниже 25 м и < 20 м/с; уборка > 140 м/с
  (`auto_gear`). Подсказка `gear_suggest` в HUD-данных.

## Навигация
- T — цели среди `Universe.get_bodies()` по расстоянию. R — автопилот: разворот на цель → WARP (если не mass lock
  и далеко) / CRUISE / SPACE → торможение по `k·(d − orbit)` → остановка на безопасной высоте
  `max(2·atmosphere_height, 0.3·R, 5 км)` (Terra Nova: 48 км). Ручной газ/мышь отключают автопилот.
  Проверено (`--demo=autopilot`): с 3000 км, нос от планеты → разворот 3 с, варп, выход, остановка на ~47 км за ~16 с.

## Pilot API (для game mode / пешего режима)
```gdscript
var is_piloted: bool
func enter_pilot() -> void                 # закрывает рампу, камера корабля current, Universe.set_focus(self), захват мыши
func exit_pilot() -> Transform3D           # только если can_exit(); иначе IDENTITY и остаётся в кресле
func can_exit() -> bool                    # landed или |v| < 3 м/с
func get_exit_transform() -> Transform3D   # ExitPoint на земле (по функции высоты), up = локальная вертикаль, лицом по курсу
func get_pilot_seat_transform() -> Transform3D
func get_camera() -> Camera3D              # активная камера корабля (chase/cockpit)
func get_hud_data() -> Dictionary
func teleport(xf: Transform3D, v := Vector3.ZERO, frozen := false)
func set_mode(m) / cycle_mode() / full_stop() / set_gear(down, instant) / toggle_flight_assist() / cycle_target() / toggle_autopilot()
signal pilot_entered
signal pilot_exited(exit_xform: Transform3D)
signal mode_changed(mode), landed_changed(landed), gear_changed(down), warp_engaged, warp_dropped, hud_message(text)
```
`get_hud_data()`: `speed, vertical_speed, mode (int 0..4), mode_name, mode_max_speed (текущий потолок),
altitude (над рельефом/водой, от опор; −1 без тел), body_name, target_name, target_distance (до поверхности, −1 нет),
throttle, gear_down, landed, flight_assist, atmosphere_density, heat (0..1), autopilot` + доп.: `warp_state (0/1/2),
warp_spool, boost, mode_suggest (−1/0..4), gear_suggest, can_exit, message`.

Корабль работает и без менеджера: `start_piloted = true` или `enter_pilot()` (так делает `flight_test`).
Клавиша F (interact) в корабле не обрабатывается — вход/выход делает game mode. После `exit_pilot()`
корабль сам держит позицию (FA, если не сел) и не трогает фокус Universe/камеру — их забирает игрок.
Корабль должен быть **прямым ребёнком** `Universe.world_root` (для сдвига мира в варпе).

## VFX
- Двигатели: `ShipVisual.set_thrust` от продольной тяги (+boost, варп), холостой 0.06.
- RCS: GPUParticles на 10 маркерах `Thruster_*`, интенсивность из командованных линейного и углового ускорений
  (сила/момент каждого сопла) → видно, какие сопла держат корабль при зависании и повороте. Локальные координаты.
- Вход в атмосферу: overlay корпуса (кромки + наветренные грани светятся, «потёки» по потоку), ударная волна
  (параболоид у носа по вектору скорости), плазменный след, искры, оранжевый OmniLight.
- Конденсация: конус пара за фонарём + следы с законцовок крыла (и в резких виражах).
- Космическая пыль: 420 штрихов в кубе 90 м вокруг камеры, длина от скорости (лог-растяжка выше 700 м/с).
- Варп: раскрутка — сужение FOV и тряска, включение — вспышка, +24° FOV, туннель штрихов, радиальный блюр/хроматика.
- Пыль под кораблём при зависании < 40 м (цвет — грунт/брызги над водой).
- Камера: FOV 68→78 по лог-скорости, лаг ориентации, отъезд при ускорении, тряска (форсаж, турбулентность ρ·v, нагрев, удары, варп).

## Тестовая сцена
```bash
tools/shot.sh scenes/test/flight_test.tscn --shots=chase_space,reentry,low_flight,landed,warp,cockpit,hover \
  --outdir=docs/screenshots/s3/flight --sky_face=1024
FPS=30 RES=1280x720 tools/movie.sh scenes/test/flight_test.tscn docs/screenshots/s3/flight/reentry.mp4 7 --demo=reentry
FPS=30 RES=1280x720 tools/movie.sh scenes/test/flight_test.tscn docs/screenshots/s3/flight/landing.mp4 8 --demo=landing
godot --headless --fixed-fps 60 --quit-after 1500 scenes/test/flight_test.tscn -- --demo=takeoff --clouds=0   # телеметрия в лог
```
Демо: `reentry, landing, hover, warp, autopilot, takeoff, orbit`. Аргументы: `--clouds=0`, `--hud=1`, `--spawn=<preset>`,
`--cam_off=x,y,z --cam_look=x,y,z` (ракурс в осях корабля), `--fx_hide=<узел FX>`, `--warp_dist=`, `--probe`.
Без аргументов — пилотируемый корабль на орбите 30 км с отладочным HUD (интерактивно на Windows).

Тест-сцена дублирует `terra_nova.tres` с `atmosphere_height = 24000` (как визуальная атмосфера), подмешивает
ambient/экспозицию и гасит звёзды по плотности воздуха — заглушки до системного освещения.

## Что хорошо / что слабо
Хорошо:
- Вход в атмосферу (`reentry.png`, `reentry.mp4`): раскалённые кромки, плазменная оболочка, искры, облака внизу — эпично.
- Варп: раскрутка → вспышка → туннель штрихов + радиальный блюр; экспоненциальный разгон/торможение
  (12 000 км за ~6 с, выход из варпа сам на ~320 км, дальше круиз до 48 км).
- Посадка: мягкое касание (ограничитель снижения), подвеска на склоне, «замки» — ни дрожания, ни сползания;
  взлёт, автопилот, запрет круиза в атмосфере проверены демо с телеметрией.
- Floating origin на любых скоростях: корабль всегда в (0,0,0), в варпе мир сдвигается каждый тик.

Слабо / не сделано:
- Ощущение мыши/виртуального джойстика проверено только скриптами (в облаке нет интерактива) — коэффициенты
  (`mouse_sensitivity`, `mouse_return`, `stick_expo`, скорости поворота по режимам) нужно подстроить на Windows.
- Нет физической интерполяции (physics 60 Гц): на мониторах 144 Гц возможна микро-ступенчатость мира;
  решение — `physics/common/physics_interpolation` (общая настройка проекта, не трогал).
- Плазменная оболочка — геометрическая (параболоид), при взгляде точно сзади читается слабее; нет heat-shimmer (искажения).
- Пыль при посадке — простые биллборды (крупные «клубы»), цвет не берётся из текстуры грунта.
- Конус конденсации — тонкое кольцо-ударная волна; следы с законцовок на стоп-кадрах отключены
  (в реальном времени съёмки частицы рвутся), в видео/игре работают.
- Кабина: яркий дисплей модели (эмиссив ShipVisual) бликует; интерьер упрощён (вопрос к модели).
- В кабине far = 500 км: дальние тела не видны без scaled space (общая задача системы).
- Аэродинамика без сваливания/подъёмной силы крыла; в режиме ATMOSPHERE корабль летит «по носу» (аркадно).
- Повреждений нет: удар о рельеф = отскок + тряска камеры.
